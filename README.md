# Python-Snake-Water-Gun-Game

# 🐍 Snake, Water, Gun Game

A simple command-line game built using Python where the player competes against the computer in the classic Snake, Water, Gun challenge.

This mini-project was created as part of my Python learning journey to practise programming fundamentals, strengthen logical thinking, and understand how conditional statements work in a real program.

## 🎮 How to Play

The game has three choices:

- 🐍 **Snake (s)** beats 💧 Water
- 💧 **Water (w)** beats 🔫 Gun
- 🔫 **Gun (g)** beats 🐍 Snake

If both the player and the computer choose the same option, the game ends in a tie.

## ✨ Features

- Random computer choices using Python's `random` module.
- User input through the command line.
- Winner determination using conditional statements.
- Tie detection.
- Input validation for invalid choices.
- Simple and beginner-friendly implementation.

## 🛠️ Technologies Used

- **Language:** Python
- **Modules:** `random`
- **Concepts:** Functions, conditional statements, user input, logical operators, random number generation, and string handling.

## 🚀 Getting Started

### Prerequisites

Make sure Python is installed on your computer.

Check your Python installation by running:

```bash
python --version
```

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd snake-water-gun-game
   ```

3. Run the Python file:

   ```bash
   python game.py
   ```

   Replace `game.py` with your actual Python filename if it is different.
